### Decisions I made while building
- **Trigger events also get a daily time window**, labelled "Zeitfenster (Auslöser scharf)". Without it the
  per-station override column had no visible source of truth — the event carried a window the form never showed.
- **`<html lang>` now follows the DE/EN switcher.** Native date/time inputs were rendering as 12/01/2026 and
  08:00 AM in a German prototype.
- Generic drag helpers refactored to `listFor(type)` + `render()` instead of hardcoded
  `specialAnnouncements : displayTexts` and `navigate('spc'|'texts')` — playlists reuse the same reorder code.

### Note to self
Two traps cost time: (1) `python3 -m http.server` inherits the *shell's* cwd, and a stale server on the same
port silently served the workspace root — always `curl | grep` for a string you just added before trusting a
