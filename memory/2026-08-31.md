**Two bugs in the conversion method, found and fixed — worth keeping:**
1. *Pale tints landing on greys.* The neutral threshold was chroma < 0.06 (≈15/255), so
   #E8F5E9 (chroma 13) counted as neutral and mapped to `--color-grey-10`. Same for pale
   reds → grey-5. Threshold is now 8/255; a tint keeps its family, only a true neutral may
   cross into the grey ramp. This is the failure `be0172c`'s hue guard was meant to stop and
   didn't — its own output likely carries it. **Worth re-auditing the other 13 prototypes.**
2. *A value match is not a role match.* Exact lookup handed #E0E0E0 → `--control-track` (the
   Toggle's off track) for table borders, #F5F5F5 → `--control-thumb-off` for a page
   background, #FAFAFA → `--sds-gray-bg-light` (GSP/Bootstrap stack, wrong stack entirely).
   Added a role pass that re-points by the property the token landed on.
