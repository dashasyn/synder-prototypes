## Filters v14 — V6 tabs independent, V7 header restructured (15:21–16:0x UTC)

### V6: he chose the option I argued against
> I want tabs and statuses work independently. So when the user switches tabs don't change
> selected statuses in the filter.

That's his "option B" from Aug 20, which I pushed back on then (it lets you build *Needs attention
+ Synced* = guaranteed empty). He's now asked for it directly, so I built it and said plainly what
it costs rather than re-arguing.

**The useful reframe:** V6 and V8 are now a *matched pair on one trade-off*. V6 = independent, the
contradiction is buildable. V8 = scoped, the contradiction can't be expressed. That's a better
comparison than two variants that differ in layout only — and it means the pushback wasn't wasted,
it just became the other half of the experiment.

**The mitigation that makes independence defensible:** tab counts are computed **with the status
filter applied**. Select Synced and *Needs attention* reads **0 before you click it**. That's the
line between a trade-off and a trap. And it's what actually separates this from FLT-2: that bug
had the two controls disagreeing *silently* while the dropdown asserted something untrue. An empty
list you can predict is not the same class of thing as a label that lies. Worth remembering — I'd
been treating "two controls on one dimension" as the defect, when the defect was really "two
controls that lie about each other".

**Knock-ons I had to work out rather than being told:** no more dashed *partial* tab state (two
values, so a tab is either active or not) · the tab counts as an applied filter so `Clear filters`
clears it and shows up when only the tab is set · **the deep-link now resets the tab to All**,
because landing on a tab that excludes the arriving status would show an empty list for a link the
user just clicked.

### V7: search row below the header
Moved search + Filters out of the header's action group onto their own row, per his screenshot.
Kept `Download report` in the header — his instruction was to *move* two things, not remove a
third. Placeholder matched to the screenshot's "Search by customer". Count line removed.
