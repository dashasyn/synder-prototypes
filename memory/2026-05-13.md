## Morning Idea — Accessibility Edge Case
- **Topic:** Stations grid keyboard/screen reader accessibility in Grunddatenversorgung v3
- **Angle:** Accessibility edge case
- **Idea:** The Route → Stations tab is a 2D grid (station rows × message-type columns) with badge cells. Screen readers hear just "button" per cell; keyboard users Tab through 30+ cells. Fix: `role="grid"` + `role="gridcell"` + `aria-label="[Station] · [Message type] · [Status]"` per cell. Arrow keys navigate natively. Worth baking in before building the prototype. ~20 min. The Default/Custom/Missing badge states (agreed May 6) are the exact semantic payload for aria-label.
