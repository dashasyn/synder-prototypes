**What the audit found before I touched anything:** the `<link>` swap was the easy part. The

**Method for the colour conversion** (worth reusing):
- exact value match → any token holding that value
- approximate match → restricted to the published palette + core text/bg/border tokens, AND
  required to be in the same hue family, AND within a weighted RGB distance of 42
- third-party brand colours on an explicit allowlist → never touched
- anything else → left raw and reported, not guessed
First attempt used pure colour distance with no hue guard and was mapping pale greens onto
greys (#F0FAF0 → #F5F5F5). The hue guard is what makes this safe.
Substitutions confined to `<style>` blocks so JS colour strings were never rewritten.

**Result:** 60 hexes tokenised, 16 brand colours preserved, 59 left for Ignat's decision
