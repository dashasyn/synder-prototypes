Two test-harness lessons:
- A `file://` link to a **directory** (`./banner-builder/`) loads Chrome's directory listing, whose
  own script throws `start is not defined`. A click-through assertion is only meaningful against
  the published URL; locally assert the href plus the target file on disk.
- Lucide **keeps the `data-lucide` attribute on the generated `<svg>`**, so "no `[data-lucide]`
  left" is not the right test for a bad icon name. The real signal is a surviving `<i data-lucide>`.
