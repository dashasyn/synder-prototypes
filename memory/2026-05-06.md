## Grunddatenversorgung v3 — Design Decisions (2026-05-06 ~08:30 UTC)

Conversation context: Ignat wants to build v3 of the Grunddatenversorgung (Transit Data Manager) prototype.

**Variant chosen:** A (sidebar nav, not tabs)

**Agreed structure / architecture:**
- Routes belong to schedules (not shared globally). Deep copy on schedule duplicate.
- URL pattern: `/schedules/SCH001/routes/RT001` (not `/config/routes/RT001`)

**Pages to include in v3 sketch:**
1. Schedules list — table with duplicate action per row
2. Schedule detail — list of routes inside
3. Route detail — list of messages/stops inside, Details + Stations tabs
4. Rules — table with rule type column (or two lists), scope field (Whole route / Origin / Intermediate / Destination / Specific station), "What" as template builder with chips + placeholders
5. Configuration → Placeholder library — list of {Next station}, {Current station}, etc.
6. Sound library — simple table: track name, language, description, delete

**Key design decisions confirmed:**
- Placeholder library needed under Configuration: {Next station}, {Current station}, etc. Free-text allowed (e.g. "Doors closing" typed manually)
- Rules: one table with Rule Type column (or two lists) — both options acceptable
- Sound library: simple table, columns: Track name, Language, Description, Delete
- Station override indicator: Default (grey) / Custom (blue) / Missing (red) badge per cell in Route → Stations
- Duplicate schedule: add duplicate action on Schedules table row
- "Needs review" third status (alongside Complete/Incomplete)
- "Sound rules: 15" → change to "15 rules · 12 reviewed" or progress bar
- From/To on Route Details derived from first/last station (not independently editable)
- Drift indicator: "Used in 4 schedules · 1 with overrides" on Station configuration row

**Status:** Decisions made, v3 build not yet started. Next step: build the sketch HTML prototype.
