## Validator pipeline v2 — enforcement rework (main work of the day)

Ignat opened with "agents are overloaded with information" and asked for a step-by-step flow for
subagents. Instead of redesigning prompts I checked the artifacts, which changed the diagnosis
entirely.

**What the audit found** (only saved round: `.synder-state/settings-rework/validators-r3/`, Aug 3):
- Trust validator never ran — not once. The one lens written from a real bug (FLT-2).
- 145 findings against a cap of 20. Cap had been applied per prototype variant (`CLR-A1`, `UX-VD3`).
- Schema drift: `per_prototype` wrapper instead of the flat contract.
- `findings-log.json` never existed anywhere → every round was a cold full re-review.
- Protocol saved to and globbed `projects/prototypes/<slug>/`, which doesn't exist.
- `TASK_BRIEF.md` never filled in once; no `reference.json` ever produced.
- **No harness at all.** `scripts/` had two unrelated files. Nothing spawned validators, truncated
  findings, or wrote the log. Every volume control was a sentence in markdown.

**Built today** (Ignat: "Update everything that needs to be updated"):
- `scripts/validator-check.js` — manifest + verify. Declares the round before spawning (the specific
  fix for Trust's invisible absence, since a validator producing nothing can't be detected without a
  declared expectation), then fails the round on missing/malformed/over-cap/unevidenced output and on
  a missing findings log. Also checks its own downstream artifact. Tested against the Aug-3 round:
  fails on all four historical counts. Tested against a clean payload: passes.
- `VALIDATOR_PROTOCOL.md` v2, v1 archived. 11 steps. Recon pass → `statemap.json` so no validator
  ever reads raw HTML again; only 2-3 relevant KNOWN_FRICTION entries per agent instead of all nine.
- All six validators rewritten: three-phase method (inventory → interrogate → select), `checked`
  coverage array, evidence requirement. Floors unified at 70 — the confidence number is
  self-reported and uncalibrated, so evidence is the real gate.
- New A11Y validator (6th lens).
- `vocabulary.md` injected into Domain/Clarity/Fidelity — it had never reached any agent while two
  lenses argued about terminology. Found via Claude's "shared context file" point.
- Domain/Clarity tiebreak (Claude's idea, adopted): book-affecting terms keep the precise word;
  Clarity's fix becomes a tooltip/helper text, never a relabel.
- `personas/MISSES.md` — failure corpus, 5 cases seeded with regression prototypes.
- `WORKFLOW_AS_IS.md` reordered by leverage; `HOW_WE_WORK.md` noted as pre-v2.
- `AGENTS.md` updated: six validators, enforcement not optional.
