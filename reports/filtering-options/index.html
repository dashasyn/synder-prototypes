Filtering Options

Exploring different filter UI patterns to reduce vertical space while maintaining usability. All four variants filter the same 24-row dataset. Every variant stages its filters — the list is only re-queried when you click Apply.

Current: Full Filter Bar

All filters visible at once. Takes significant vertical space but everything is discoverable. Changes are staged — nothing applies until you click Apply.

Transactions

Unapplied changes — click Apply to update the list.

Popular Filters + All Filters in Sheet

The most-used filter dimensions (Date range, Status, Platform) as dropdown selectors — same look and behavior as the full filter bar. Selections are staged; the list is only re-queried on Apply. "All Filters" opens a sheet with the complete set, including Amount and Customer.

Transactions

Unapplied changes — click Apply to update the list.

All Filters

Filters as Chips (Stripe Style)

Each filter is one dropdown chip — the chip itself shows its selected value and carries its own remove (×). Selections are staged; the list is only re-queried on Apply. "Add filter" only offers filters that aren't already on the bar. Status and Platform support multiple values.

Transactions

Unapplied changes — click Apply to update the list.

Filters as Button + Applied Chips

Single button opens a filter popover. Selected filters appear as removable chips below it. Nothing reaches the list until Apply — removing a chip stages the change too. Badge shows the selected count.

Transactions

Unapplied changes — click Apply to update the list.
