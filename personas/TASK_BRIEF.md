# Task Brief Template

Use this template every time you submit a prototype task. Fill in all fields.
Incomplete briefs will be sent back before any work starts.

---

## Task Brief

**Task name:** [Short descriptive name, e.g., "Reconciliation — Not Matched tab redesign"]

**Source:**
- Jira ticket: [e.g., SD-17432]
- Figma link: [node URL or frame name]
- Existing screen URL: [live demo URL if applicable]

**What needs to be built:**
[2-5 sentences. Describe the screen/flow, what state it should show, and what the user is trying to accomplish.]

**What changed vs. existing:**
[List only the delta — what's new or different. "Same as current but with X added" is fine.]

**Required states to include:**
- [ ] Default / loaded state
- [ ] Empty state (no data)
- [ ] Loading state
- [ ] Error state
- [ ] Other: ___

**Validators to run:**
- [ ] UX Validator (usability)
- [ ] Domain Validator (accounting correctness) — include if the screen has financial terms/actions
- [ ] Clarity Validator (business owner perspective) — include if the screen is user-facing
- [ ] Fidelity Validator (vs. reference) — include only if there's a reference design to compare

**Focus area for this round:**
[What should validators pay most attention to? e.g., "Focus on the action buttons and empty state copy"]

**Known issues to ignore:**
[List anything you already know is wrong and don't want flagged, e.g., "Navigation is placeholder only"]
