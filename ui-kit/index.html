How to use this page

This page is the single source of truth for Synder prototypes: values (tokens, components) come from synder-ui-kit.css, checked against the Figma library and against production (Transaction reconciliation, measured 2026-10-29). Rules below are how to use them. If a prototype needs something that isn't here, it gets added here first, never restyled locally.

Rules — behaviour

SituationRule
Page loadSkeleton screens, not spinners. Spinners only inside a button for its own action.
Empty stateIcon + heading + one line of text + CTA. Never blank space.
Field errorBelow the field, 14px, red. Icon optional.
Destructive actionConfirmation modal whose button says exactly what happens ("Delete 3 transactions", never "Confirm" / "Are you sure?").
ToastsBottom-right, 320px, auto-dismiss 5s. No Undo link — Synder toasts don't have one.
FiltersA filter value is cleared with its ×, not by choosing "All".
Disabled controlsNever without a visible reason (helper text or tooltip).
TooltipsNever the only place important information lives.
Prefilled defaultsA hint explaining why a value is prefilled disappears when the user changes the value.
New settingGoes next to its closest existing relative, not at the top of the tab.
Side sheet / modalSide sheet 480px (wide 600), overlay --bg-overlay. Modal max 560px (wide 720), radius 8.
CopyNever present invented text as existing product copy — mark it [live copy not captured] until verified.
