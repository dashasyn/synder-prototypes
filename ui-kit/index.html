Overview

What this page is and how to use it.

This page is the single source of truth for Synder prototypes: values (tokens, components) come from synder-ui-kit.css, checked against the Figma library and against production (Transaction reconciliation, measured 2026-10-29). Rules are how to use them. If a prototype needs something that isn't here, it gets added here first, never restyled locally.

Each component section has its full spec on top and a live demo under it. Every rule row has its own link: hover the row and click link to copy it.

Rules: behaviour

How things act: loading, empty, errors, destructive actions, toasts.

SituationRule
Page loadSkeleton screens, not spinners. Spinners only inside a button for its own action.
Empty stateIcon + heading + one line of text + CTA. Never blank space. Example →
Field errorBelow the field, 14px, red. Icon optional. Forms →
Destructive actionConfirmation modal whose button says exactly what happens ("Delete 3 transactions", never "Confirm" / "Are you sure?"). Modal →
ToastsBottom-right, 320px, auto-dismiss 5s. No Undo link — Synder toasts don't have one. Toast →
FiltersA filter value is cleared with its ×, not by choosing "All". Filter bar →
Disabled controlsNever without a visible reason (helper text or tooltip).
TooltipsWhite, 1px #DFE4EC border, dropdown shadow, 14/20 dark text. Never the only place important information lives. Ignat 2026-10-30
Prefilled defaultsA hint explaining why a value is prefilled disappears when the user changes the value.
New settingGoes next to its closest existing relative, not at the top of the tab.
Side sheet / modalModal max 600px (720 / 900 wide), side sheet 480px (600 wide). Full spec →
CopyNever present invented text as existing product copy — mark it [live copy not captured] until verified.
