Overview

What this page is and how to use it.

This page is the single source of truth for Synder prototypes: values (tokens, components) come from synder-ui-kit.css, checked against the Figma library and against production (full property audit of 15 production pages, 2026-11-03/04; production wins where Figma disagrees, by Ignat's decision). Rules are how to use them. If a prototype needs something that isn't here, it gets added here first, never restyled locally.

Each component section has its full spec on top and a live demo under it. Every rule row has its own link: hover the row and click link to copy it.

Starting a new Synder prototype? Copy the starter template (page frame, page header, filter bar, tabs, table, pagination — kit classes only) and build inside it. Layout rules: Page layout.

Source of truth for production look: the newest MUI screens — Transaction reconciliation, Summaries, "Choose your way". The 14px minimum, no-Undo toasts and ×-to-clear filters stay above production (Ignat's rules).

warningLegacy screens — don't copyBootstrap popups (Add integration and similar, white backdrop) · old Transactions list (pill chips, 13px text) · glyphicons and FontAwesome icons · the Helvetica date picker. Use the kit versions instead (Modal, Statuses, Material Icons, Date picker).

Rules: behaviour

How things act: buttons, links, numbers, loading, empty, errors, destructive actions, toasts. The first three rows are Ignat’s Figma UI kit rules (2026-11-11).

SituationRule
Page loadSkeleton screens, not spinners. Spinners only inside a button for its own action.
Empty stateIcon + heading + one line of text + CTA. Never blank space. Example →
Field errorBelow the field, 12px, red (as in product code). Icon optional. Forms →
Destructive actionConfirmation modal whose button says exactly what happens ("Delete 3 transactions", never "Confirm" / "Are you sure?"). Modal →
ToastsTop centre, solid green / red, auto-dismiss 5s. No Undo link — Synder toasts don't have one. Toast →
FiltersA filter value is cleared with its ×, not by choosing "All". Filter bar →
Avoid disabling buttonsButtons stay enabled unless the task explicitly says otherwise. If the action isn't possible yet, let the user click and show the problem where it is: e.g. the empty required select turns red with "Required" under it. A disabled button is the exception, and then only with a visible reason. Example →
Don't open new blank pages unless neededButtons open content on the same page (unless the task says otherwise). "Learn more" always opens in a new tab. Links open in a new tab (target="_blank"). Buttons and links must still support standard browser behaviour (right-click → open in new tab, Cmd/Ctrl+click), so navigation is a real <a href>, not a click handler on a div.
Top banner: centred groupThe message and its button sit together in the centre of the banner, 16px apart. Never text on the left and the button at the far right. .synder-banner does this by default; don't override justify-content.
Number and amount formattingGroup thousands with commas; decimals (cents) after a dot: 109,928,376.78, never 109928376.78. Applies to every amount, count and total in tables, cards and messages.
TooltipsWhite, 1px #DDE4ED border, light shadow, padding 4×8, max 300px, 14/20 #000 text, opens below-left. Never the only place important information lives. Ignat 2026-10-30
Prefilled defaultsA hint explaining why a value is prefilled disappears when the user changes the value.
New settingGoes next to its closest existing relative, not at the top of the tab.
Side sheet / modalConfirm dialog 440px (.modal-confirm); form modal 480px (560 / 960 wide); side sheet 560px (1024 wide). Full spec →
CopyNever present invented text as existing product copy — mark it [live copy not captured] until verified.
