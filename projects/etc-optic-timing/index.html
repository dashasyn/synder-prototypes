233 — the optics

  • Master data for trackside optics: station, platform, Aramis track, location, direction, properties
  • Station / platform / track arrive by import from FMSILA.XML and are read-only here
  • Re-import must never overwrite the hand-maintained fields
  • Each optic reports state on the Aramis 2806 message

668 — the timing

  • Lead times and repeat interval per station, over a system-wide default
  • Per Station + Business rule + Platform, choose the trigger: estimated time or a real optic event
  • One shared “Based on” control, defined in 233 and reused here
  • Every optic reference links back to its record in 233
