Products/Servicesv2 treated 6 dropdowns as unlabelled and wrote “Select…” helpers for them. They sit inside sentences, so v3 rewrites the sentences.
Auto-sync and Auto-importv2 reported no warning. The page has one, and turning Auto-sync on also turns Auto-import on. Only the wording of that warning is in scope now.

House rules

  1. Toggle helpers state what happens when the switch is on, in present tense. Never If you enable / If enabled / If disabled / When "ON" / Enable this setting to / It is an option to / By enabling this configuration / This setting allows you to.
  2. Synder is the subject when Synder does the work. QuickBooks is the subject when QuickBooks does it. Never “app”, “the application” or “system”.
  3. One sentence. Add a second only when the off state isn’t the obvious opposite, a dependency has to be stated, or a consequence would surprise. Write the off state as When off, …
  4. Never “this setting / this option / this configuration”.
  5. Picker and field helpers start with Select (or “Select or type” for vendor and customer names). Never “Please,”, “Specify”, “Choose or type in”.
  6. “Your books” for the accounting company, QuickBooks only for QuickBooks objects (tax codes, locations, Doc Numbers, payment methods). Never “accounting system / accounting platform / your company / accounting”.
  7. “Your integration” when the key has no integration placeholder; the integration name ({0}) when it has one. Never “payment processor / provider / sales platform” in helpers.
  8. Links are plain words. “Learn more”, “Change time zone”, “Build a Smart Rule”. No >>, no “page>>”, no “here”.
  9. “(recommended)” goes right after the thing it recommends, never in the middle of a clause.
  10. (?) tooltips follow the same rules and add something the helper can’t: both states, a priority rule, a definition. Never the helper again, word for word.
  11. Revealed fields describe the field, never the switch the user just turned on.
  12. Sync, not synchronize/synchronization. Sentence case for labels; document names lower case in running text (invoice, bill, sales receipt).
  13. Messages give the reason, then what to do. Prerequisites read: Turn on/off X in QuickBooks first: A → B → C. No “You should”, “Please note that”, ->.

Hand-off

  • Every row lives in backend/grails-app/i18n/messages.properties unless it’s marked hardcoded in GSP or new key. The key is under each “Where” cell.
  • Hardcoded in GSPs: the blue “Turn on auto-sync” title (common/_generalSettings.gsp), “product with” and the Original/Common options (intuit/_itemSettings.gsp).
  • One new key: a helper for Collect items for product mapping.
  • Keys with {0} keep it. The proposals show it filled in (usually Stripe).
  • Rows marked meaning from synder-mcp glossary describe behaviour taken from the synder-mcp glossary, not traced through the sync code. Check those two with a dev.
  • Out of scope: Xero, QuickBooks Desktop, rows for other integrations (Shopify, Square, PayPal, Amazon, etc.), RevRec-only rows (Track refunds), and global errors such as default.error.
