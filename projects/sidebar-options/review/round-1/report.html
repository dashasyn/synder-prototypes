Target: sidebar-options. Lenses: UX ×3, Domain, Clarity on Hover chevron; UX ×1 on each other option (they share menus, copy and the org selector). Not run: Trust, A11Y, Fidelity (not requested, no spec). All 5 rounds passed validator-check verify.

Medium · ux1 · UX-1 · Admin view · org selector, current organization after a switch
In Admin, after switching, the current org has no check mark and is missing from 'Recently selected'. The other three views check-mark the current org.
Impact: A support admin moving between customer orgs can't confirm in the list which org they are in, and the same selector reads differently by role.
Fix: Mark the current org with the same check row as the other views, either at the top of Recently selected or as its own first row.
Evidence: action: Admin view: typed 'tea', pressed Enter, picked Tea Leaf Collective, reopened the selector; observed: current-org row: null; Recently selected = PT_3, Granite Peak Dental, Northwind Bookkeeping, Summary Am Rec, Summary_test (no Tea Leaf Collective); no check anywhere.
