2Sync on/off per store

Can sync be turned on for one store and kept off for another?

3Do we need both Pause and Disable?

Pause keeps reading QuickBooks and queues changes. Disable stops reading, and changes made while it's off are never sent. Is there a case where Disable is needed instead of Pause?

If not, the main control becomes Pause / Resume (or a toggle), and Disable moves into a menu behind a confirm.
